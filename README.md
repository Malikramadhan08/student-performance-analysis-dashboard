📊 Student Performance Analysis Dashboard

An interactive dashboard built in **Microsoft Excel** to analyze student academic performance using data visualization, KPI cards, PivotTables, PivotCharts, and slicers.

---

📖 Project Overview

The goal of this project is to transform raw student performance data into an interactive dashboard that enables users to explore academic trends and gain meaningful insights. The dashboard allows dynamic filtering across multiple categories, making the analysis more efficient and user-friendly.

---

🎯 Project Objectives

- Clean and prepare raw data for analysis.
- Analyze student performance across different demographic factors.
- Build an interactive dashboard using Microsoft Excel.
- Present key insights through effective data visualization.
- Support data-driven decision-making.

---

📂 Dataset Information

| Item         | Details                                                                                                                   |

| **Dataset**  | Students Performance Dataset                                                                                              |
| **Source**   | Kaggle                                                                                                                    |
| **Records**  | 1,000 Students                                                                                                            |
| **Features** | Gender, Race/Ethnicity, Parental Education, Lunch Type, Test Preparation Course, Math Score, Reading Score, Writing Score |

📈 Dashboard Features

- Interactive slicers for dynamic filtering.
- KPI cards showing average Math, Reading, Writing, and Total Scores.
- PivotCharts for comparing student performance.
- Clean dashboard layout designed for easy interpretation.
- Key Insight section highlighting important findings.

---

💡 Key Insights

- Students who completed the test preparation course achieved higher average scores.
- Reading has the highest average score among all subjects.
- Students with parents who have higher education levels tend to perform better academically.
- Lunch type shows a noticeable relationship with academic performance.
